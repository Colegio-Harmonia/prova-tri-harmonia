# Guia de ativação das notificações no Google Chat

## Para que serve

O Prova-tri envia notificações privadas pelo Google Chat quando uma prova é
atribuída para sua revisão. Cada professor recebe somente as mensagens
destinadas à própria conta.

## Ative em cinco passos

1. Abra o Google Chat com seu e-mail institucional.
2. No menu **Apps**, abra **Prova-tri**.
3. Envie a mensagem `Teste` para o app.
4. Clique em **Conectar minha conta**.
5. Entre no Prova-tri com sua conta institucional e aguarde a confirmação.

Depois de ativado, uma nova mensagem ao app responderá que as notificações
privadas já estão ativas.

## O que você receberá

- Aviso de prova atribuída para revisão.
- Link direto para abrir a prova no Prova-tri.
- Somente avisos relacionados às suas atribuições.

## Se algo não funcionar

- Se não aparecer o cartão de conexão, envie `Teste` novamente ao app.
- Se o navegador abrir `localhost`, feche essa aba, retorne ao Google Chat e
  envie `Teste` novamente. O endereço correto do Prova-tri é
  `https://prova.colegioharmonia.com.br`.
- Se ainda não houver confirmação, envie uma captura de tela para a
  coordenação.

## Roteiro de teste para outro professor

1. O professor ativa a conversa seguindo os cinco passos acima.
2. A coordenação atribui uma prova de teste apenas a esse professor.
3. O professor confirma que recebeu a mensagem privada no app Prova-tri.
4. O professor abre o link e confere se a prova exibida é a dele.

Não é necessário criar grupo ou espaço coletivo no Google Chat.
